可选功能 · Supabase 免费项目即可起步

站点已接入云端 · 无需填写数据库配置

游客可直接使用记录功能。需要跨设备同步时，在下方用账号密码登录；其他用户不需要配置数据库。

首次配置只需三步
  1. 在 Supabase 控制台 创建项目，并执行下载包里的 supabase.sql。
  2. 在项目设置的 API 页面，复制 Project URL 和 publishable key（或旧版 anon key） 填在下面。
  3. 在 Authentication → Sign In / Providers 启用 Email，确认注册与邮箱验证策略。账号密码登录平时不需要邮件链接。

千万不要填写 service_role / secret key。 这里只能使用公开客户端密钥，数据隔离由数据库 RLS 策略提供。

每人用自己的邮箱和密码登录。注册是否需要首次验证邮箱，取决于网站管理员在 Supabase 的设置。

两种模式有什么区别？

本机模式
无须注册，填写后立即保存在当前浏览器。清理浏览器数据可能丢失，建议导出备份。

云端模式
需要时登录；经本人确认把游客记录合并到账号。以后手机与电脑用同一账号可查看云端记录；断网时变更暂存到当前设备，恢复网络后同步。

关于隐私

身体感受属于私密记录。游客记录保存在当前浏览器，使用共享设备时其他人可能看见；建议使用私人设备、HTTPS，定期备份。不同账号之间不会自动合并游客记录，必须由当前登录者确认。
